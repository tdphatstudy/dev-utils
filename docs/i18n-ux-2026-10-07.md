# Interface, tray and reliability changes

Settings → Language offers 13 languages plus Follow system. The native tray
shares the preference, including when the main window is closed. The preference
is stored in the existing user-data profile; no vault formats or data locations
change. Missing, malformed, oversized or unsupported preference files use the
system language, falling back to English if it is unsupported.

Translations are local source catalogs with explicit English fallback. Navigation,
Settings, shared actions, help, security consent and tray copy are translated.
Specialized descriptions, some deeper tool controls and backend/analysis
diagnostics still use English. Language variants currently share a single
Simplified Chinese and Portuguese catalog. Translation wording has automated
structural checks, not a professional linguistic review of all 13 languages.

User input and code are never translated. Switching language preserves tool
state; technical selectors retain their original values. Arabic changes the
interface direction and keyboard navigation in segmented controls while keeping
code, hashes, URLs and numeric inputs left-to-right. Labels and disclosures use
the existing macOS-style surfaces and reduced-motion preference.

Each tool has a How to use disclosure with an input/action/result sequence.
Wide split panes show their labels; compact layouts retain reachable tabs.
The tray groups quick actions, exposes busy state, Settings, language and manual
Private Box lock. Capture/copy/server/native-menu failures are contained and
reported using generic messages. A missing tray allows normal last-window exit.

Renderer process failure prompts Reload workspace or Close and clears vault
keys before recovery. Unsaved renderer input can be lost. Recovery does not
modify encrypted files and requires unlocking the box again. It never loops on
automatic reload. Main handlers continue validating senders and payloads; CSP,
sandbox and context isolation are unchanged.

Verification commands:

```sh
pnpm test --maxWorkers=4
pnpm typecheck
pnpm build
pnpm test:ui:i18n
pnpm test:ui:enterprise
pnpm test:ui:security-testing
node tests/ux-review-ui.smoke.mjs
pnpm test:electron:security
pnpm test:electron:packaged
```

On this Windows host, browser smoke tests use `UX_BROWSER_CHANNEL=msedge`.
Tests cover all language choices and fallback, preference persistence and write
failure, a delayed response versus a newer tray selection, preserved JSON input,
Vietnamese search without accents, Arabic consent and a real hash worker. Native
tests run the production preload/renderer against temporary fixtures, including
a forced renderer crash. Unit tests cover native tray failures and menu actions,
trusted language IPC, corrupt metadata, key zeroing and network-job cancellation.
The broad UI sweep checks all registered tools in light/dark and minimum window
sizes. Native macOS/Linux smoke testing and signed distribution are unavailable
on this Windows host. Automated checks cannot guarantee an app never crashes.

Results on 2026-10-07: 993 tests in 106 files passed; typecheck and production
build passed. The 13-language smoke, enterprise/privacy/security tool flows and
50-route light/dark sweep at both window sizes passed. Native development and
ASAR/fused-runtime tests passed, including forced renderer-crash recovery.
The Windows unpacked app was rebuilt with signing disabled; it is a local test
artifact, not a signed enterprise distribution. The build retains the existing
large SQL chunk warning; SQL remains lazy-loaded.
